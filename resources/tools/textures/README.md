# Generated textures

PNG output of the Scene panel's **Texture tools**:

- procedural generates: solid, checker, gradient, radial, white noise, perlin
  noise, cellular
- normal maps baked from a height image (Sobel on luminance)
- packed ORM maps: R occlusion, G roughness, B metallic

The folder ships empty; files written here are authored content and can be
adjusted or deleted freely. `GX_GFX_TEXTURE_DIR` redirects output (used by the
headless `make gfx-texture-check`).
